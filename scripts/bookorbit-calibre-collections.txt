# Series de la biblioteca Calibre "75.452" que son colecciones editoriales, no sagas.
#
# La 75.452 (metadatos de epublibre) guarda la colección de la editorial en el campo
# "serie" cuando el libro no pertenece a ninguna saga: "Nova #247" para El marciano,
# "Bolsilibros - Servicio Secreto #1796". Importadas como serie, BookOrbit mostraría una
# "saga" Nova con 119 libros de 78 autores. bookorbit-calibre.py las convierte en la
# etiqueta "Colección: <nombre>" y deja el libro sin serie.
#
# Una expresión regular por línea, sin distinguir mayúsculas, anclada al principio del
# nombre de la serie. Lo que no casa aquí se trata como saga, así que en la duda se deja
# fuera: una colección tratada como saga se ve rara, una saga tratada como colección
# pierde el orden de lectura.
#
# Una línea que empieza por "!" es una excepción: la serie que case se queda como saga
# aunque también case con una colección (series de un personaje dentro de un bolsilibro).
#
# La romántica mete la saga entre paréntesis: "Jazmín (Matrimonio de conveniencia, 2)" es
# la colección Jazmín y la saga "Matrimonio de conveniencia" número 2. El script hace esa
# separación solo, no hace falta listarlas.
#
# Revisado contra las 358 series con 3+ autores el 2026-10-17. Las franquicias con muchos
# autores (Star Wars, Warhammer, Dragonlance, Reinos Olvidados, Star Trek, BattleTech,
# Conan, James Bond, Mundo de tinieblas...) son sagas y no están aquí.
